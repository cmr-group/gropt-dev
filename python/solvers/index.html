    Solving

    gropt.SolverGroptSDMM

    set_general_params 

    set_general_params(min_iter: int = 1, max_iter: int = 2000, log_interval: int = 20, gamma_x: float = 1.6, max_feval: int = 12000)

    Set general parameters for the SDMM solver.

    Parameters:

    Name Type Description Default
    min_iter int

    Minimum number of iterations for the main SDMM loop. The solver will run for at least this many iterations. Defaults to 1.

    		 1
    max_iter int

    Maximum number of iterations for the main SDMM loop. Defaults to 2000.

    		 2000
    log_interval int

    Interval at which to log the progress of the solver. This will only be seen when verbose logging is enabled. Defaults to 20.

    		 20
    gamma_x float

    Relaxation parameter for the SDMM update step. correspond to over-relaxation, which can speed up convergence. Defaults to 1.6.

    		 1.6

    set_ils_params 

    set_ils_params(ils_tol: float = 0.001, ils_max_iter: int = 20, ils_min_iter: int = 2, ils_sigma: float = 0.0001, ils_tik_lam: float = 0.0)

    Set parameters for the indirect linear solver used in the SDMM.

    Parameters:

    Name Type Description Default
    ils_tol float

    Relative tolerance for the inner-loop indirect linear solver (e.g., CG). The ILS stops when the residual norm is less than ils_tol times the initial residual norm. Defaults to 1e-3.

    		 0.001
    ils_max_iter int

    Maximum number of iterations for the indirect linear solver per main SDMM iteration. Defaults to 20.

    		 20
    ils_min_iter int

    Minimum number of iterations for the indirect linear solver. Defaults to 2.

    		 2
    ils_sigma float

    Regularization parameter for the linear system solved in the inner loop, related to the ADMM penalty parameter. Defaults to 1e-4.

    		 0.0001
    ils_tik_lam float

    Tikhonov (L2) regularization parameter for the indirect linear solver. Adds a penalty on the norm of the solution to improve conditioning. Defaults to 0.0.

    		 0.0

    set_sdmm_params 

    set_sdmm_params(rw_interval: int = 8, rw_e_corr: float = 0.4, rw_eps: float = 1e-36, rw_scalelim: float = 1.5, grw_min_infeasible: int = 20, grw_interval: int = 20, grw_mod: float = 2.0)

    Set parameters specific to the SDMM algorithm.

    Parameters:

    Name Type Description Default
    rw_interval int

    Interval for reweighting operations. Defaults to 8.

    		 8
    rw_e_corr float

    Error correction parameter for reweighting. Defaults to 0.4.

    		 0.4
    rw_eps float

    Small epsilon value for numerical stability in reweighting. Defaults to 1e-36.

    		 1e-36
    rw_scalelim float

    Scale limit for reweighting operations. Defaults to 1.5.

    		 1.5
    grw_min_infeasible int

    Minimum number of infeasible iterations before adaptive reweighting is allowed. Defaults to 20.

    		 20
    grw_interval int

    Interval for adaptive reweighting checks. Defaults to 20.

    		 20
    grw_mod float

    Modification factor for adaptive reweighting. Defaults to 2.0.

    		 2.0
